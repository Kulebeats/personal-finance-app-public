## Implemented behavior

The reader accepts canonical graph text and separate serialized caller pins. It
checks raw bytes/hash independently of the emitter's stable-JSON graph digest,
rejects duplicate/unknown keys and ambiguous encodings, and bounds parsing and
graph cardinalities. It validates emitted members, source mappings, fixed roots,
the sole application getter edge and trusted graph reachability. The normalized
census retains parent, original kind, mode, literal specifier and occurrence count.
Builtins, internal imports, type-only declarations and unsupported cases remain
distinct. Returned data is deeply frozen and every wider certification is false.

The five known stateless facade source overlaps require exact paths and complete
matching pins. All other app/trusted overlap and byte-copy aliases are refused;
trusted source and emitted output copies are also refused. This is structural
validation of declared pins, not an independent proof that a facade has no state.
Later source/loader review and physical identity checks retain that obligation.

There are no filesystem reads, resolver calls, private acceptance brands or
application/package imports in the helper. Node builtin utilities are its only
runtime dependencies beyond the existing pure primitives module and its new JSON
helper. A declaration record grants no observation, stage, custody or execution
authority.
