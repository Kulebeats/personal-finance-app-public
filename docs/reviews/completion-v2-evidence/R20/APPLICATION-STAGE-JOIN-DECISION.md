1. **Bind the whole source declaration and root evidence.** A future closed application input must bind graph/source-output mappings, candidate, external approval pins, exact reviewed observation, runtime, package.json/package-lock and separately attributed build/harness revisions. Every package tuple retains parent, kind, mode, specifier, occurrences, selected URL/file identity and selected package-root relationship. A changed application graph gets its actual complete census;41 is not a permanent hardcoded fixture size.

2. **Capture a complete declared package census from those physical roots.** Preserve nested instances, package scopes, lock relationships, optional absence evidence and whole-package files/directories under the existing bounded capture discipline. Retain unsupported topology, missing required dependency, native addon/DLL, WebAssembly, generated-tooling and opaque/computed-data obligations as explicit blockers/dispositions. Do not generalize the two existing generated-tooling exceptions. Existing finite limits are ceilings to evaluate, not permission to raise limits, omit roots or return an accepted partial census. A census reports declaration/bytes and unresolved obligations; it does not authorize loading.

3. **Define an application manifest and stage only after the census join is reviewed.** Its identity must be distinct from the component manifest/stage. It binds all emitted application/trusted members, package census, controlling metadata, independently reviewed native/data dispositions, bootstrap sources and exact allocation. Preserve `dist/production-application.js`, `.runtime/application-bootstrap.mjs` and one `.runtime/trusted/` tree from the accepted module-identity plan. The current23-member graph is not evidence that the future bootstrap/capability closure already exists. Any added bootstrap dependency must be explicitly represented and reviewed, not smuggled in as an auxiliary harness file.

4. **Rebind the relocated physical world.** A stage copy has new file identities, parent URLs, lookup ancestry and potentially different scopes. Record exact source-to-stage mappings; verify all staged bytes/membership/absences; reconstruct package lookup from every actual staged parent and re-establish selected formats under unchanged rules. Source dev/ino, source observation hashes and equal bytes do not grant stage authority. No fallback to repository node_modules or other source paths is permitted. Preserve trusted URLs uniquely and refuse duplicate/case/query/hash/path aliases, symlinks, junctions, undeclared members and drift. Exact transport/observer integration for this stage remains unsettled; do not pretend the source-root-bound observer can already observe a new namespace.

5. **Keep structural evidence separate from live admission.** An independently pinned serialized census/stage may enter an explicit pure reader and acquire only that reader's structural private lineage. It cannot recreate the observation WeakMap record, producer admission, active custody or a live service/job capability. A genuine application stager, loading boundary and supervisor must join their own identities in the intended realm. Hash consistency and a new brand name are not authorization. Do not serialize an `admitted`, `jobsReady` or `executionAuthorized` shortcut.

6. **Establish enforcement and genuine capabilities before effectful import.** The application may import only the exact public getter; getter/installer share the same private cell; cell/factory share the genuine admission brand; ordinary packages cannot reach private issuers. Preserve the reviewed trusted parent-edge graph. Merely registering a loader hook or checking an import string does not prove this. Custody, live producer/factory admission, genuine required-job capability and one-shot installation must precede dynamic import of the effectful application. Check the getter immediately before import. Revocation is terminal, fences captured facades and retains owned cleanup.

These are the minimum joins, not a mandate to build all six layers in one change.
