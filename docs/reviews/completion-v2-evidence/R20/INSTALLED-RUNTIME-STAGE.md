## Genuine inert installed stage

`stageInstalledRuntimePackageTree(acceptedTree, nativeInput, allocation)` first
requires the existing private accepted-tree lineage before inspecting other
inputs or doing I/O. `nativeInput` is separately bounded canonical LF JSONL plus
an independently supplied expected SHA-256; it is never wrapped in the smaller
single-string canonical helper. Native, control and complete finite GeoIP data
rows must join the whole package tree by identical path/size/hash. Wrong pins,
missing/duplicate data, escape/alias collisions or changed absence obligations
refuse. Those checks compare supplied expectations; they do not authenticate
their owner or grant native execution.

The stage is a create-only union of all accepted package files/directories, exact
build artifacts, package/lock controls, controlling package metadata and the four
independently pinned trusted closure files:

- `.runtime/runtime-installed-bootstrap.mjs`
- `.runtime/runtime-installed-component.mjs`
- `.runtime/runtime-installed-data.mjs`
- `.runtime/runtime-installed-loading.mjs`

Only canonical `.local/r20-installed-component-oct28a/cases/<case>/stage` is
supported. The existing parent case directory must be safe and present; a stage
root is never reused or adopted. Failures preserve partial allocations. Copying
holds at most a source and destination descriptor together, completes partial
writes, checks source bytes/identity before and after, fsyncs and reads destination
bytes back, then rechecks source metadata, absence, stage identities and exact
staged membership. It does not retain custody after returning or claim resistance
to a hostile process with the same OS identity.

`requireInstalledRuntimeStage` accepts only the producer's genuine in-process
brand. The immutable record has exact sorted files and directories, sorted copied
absence paths, all unresolved obligations, runtime and tree/root/profile/build/
harness/native-data identities. `entryRelativePath='dist/index.js'` records
application-build provenance only. The distinct fixed
`componentEntryRelativePath='.runtime/runtime-installed-component.mjs'` and
`componentId='sharp-geoip-v1'` identify the separate component. The application
entry is copied and never imported by this producer. All four closure/custody/
runtime-identity/execution certifications remain false.
