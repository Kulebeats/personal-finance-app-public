## Supported positive proof, not a replacement syntax detector

Use only public `vm.compileFunction` with the exact string as the function body, the five parameters in Node's order, and the exact canonical target filename:

```js
compileFunction(sourceText,
  ['exports', 'require', 'module', '__filename', '__dirname'],
  { filename: targetPath, lineOffset: 0, columnOffset: 0,
    produceCachedData: false });
```

Discard the returned function without invoking, exporting, serializing or caching it. No runInContext/runInThisContext, function call, eval, require, dynamic import, module linking, source-text-module evaluation, addon, loader callback or imported selected target is allowed. Do not pass cachedData, parsingContext, contextExtensions or importModuleDynamically. VM is not being treated as a sandbox; the safety property is that selected code is never run. [Pinned public API](https://raw.githubusercontent.com/nodejs/node/v24.22.0/doc/api/vm.md), lines1208–1275.

The positive-only inference is grounded in the actual native implementation: [node_contextify.cc](https://raw.githubusercontent.com/nodejs/node/v24.22.0/src/node_contextify.cc), lines1404–1413,1533–1584,1776–1816, uses those five parameters and V8 CompileFunction. A successful CommonJS compile makes ContainsModuleSyntax return false before any ESM retry. Public compilation reaches the same primitive through ContextifyFunction::CompileFunctionAndCacheResult (lines1415–1433). A failure is insufficient to classify ESM: the native retry has further branches. Thus the proposed method recognizes only the successful branch, not the full detector. The wrapper parameters catch lexical redeclarations; a generic Script parser would not be equivalent. This proposal does not claim successful module loading, linking or evaluation.

The public bridge is visible in [lib/vm.js](https://raw.githubusercontent.com/nodejs/node/v24.22.0/lib/vm.js), lines297–344, and [lib/internal/vm.js](https://raw.githubusercontent.com/nodejs/node/v24.22.0/lib/internal/vm.js), lines125–155. Different dynamic-import host metadata governs later execution, which is forbidden here; it is not a reason to install a loader callback. The author must preserve these exact compiler inputs and independently review the positive-branch mapping. If an input class cannot be shown to use equivalent compilation semantics, leave that class unproven. No generic-parser equivalence assumption is accepted.

Decode verified bytes using fatal UTF-8 while preserving a BOM as a character; do not prepend a wrapper string, strict directive or newline, strip/rewrite a hashbang, transform syntax, transpile, or normalize text. Empty bytes are a legitimate candidate with the exact empty hash. BOM/hashbang and other edge classes require controls; if the public API does not accept a class consistently, conservatively leave it unproven. UTF-8 failure is a format-proof blocker, not replacement-character success. Compile failure returns a fixed unproven diagnostic, never an error-message-based ESM label. Transport failure, timeout, pin mismatch or malformed protocol remains refusal, not an ordinary syntax result.
