# Scripts

This directory contains local utilities, setup scripts, and generated artifacts.

## Layout

- `scripts/windows/` - Windows helper scripts for database setup and diagnostics
- `scripts/tools/` - One-off utilities and local helper scripts
- `scripts/artifacts/` - Generated logs, coverage output, and debug artifacts

## Notes

- Do not commit artifacts or local logs.
- Prefer running setup scripts from `scripts/windows/`.
