# Merchants Module

Merchant management with merge support.

## Endpoints

| Method | Path   | Auth   |
| ------ | ------ | ------ |
| GET    | /      | all    |
| GET    | /:id   | all    |
| POST   | /      | member |
| PUT    | /:id   | member |
| DELETE | /:id   | member |
| POST   | /merge | member |
